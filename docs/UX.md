# UX Strategy

## Primary journey

Map the shortest path from discovery to the business objective.

```text
Entry
  -> orientation
  -> evaluation
  -> decision
  -> action
```

## Key user questions

List what the visitor needs to understand before acting.

## Conversion points

Document primary and secondary calls to action, where they appear, and why.

## Trust signals

Specify reviews, guarantees, location, credentials, pricing clarity, policies, or other evidence that reduces uncertainty.

## Mobile behavior

Describe the mobile-first interaction priorities and any changes from desktop.

## Integration boundary

State which external systems would be connected in a real deployment and which parts are represented only as a demo interface.
